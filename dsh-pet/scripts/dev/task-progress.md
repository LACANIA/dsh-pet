# 实验性任务进度模式

任务进度模式提供挂机与任务两种模式，支持新任务询问、按会话跟踪工具活动，以及任务结束后自动回到挂机模式。功能默认关闭。

## 启用与使用

启动 DSH 前设置环境变量 DSH_PET_TASK_PROGRESS=1，或在用户数据目录 dsh-pet 下创建 task-progress.enabled 文件，再重新加载插件。未启用时，新增菜单和任务接口不会出现。

右键桌宠，进入「运行模式」选择「挂机模式」或「任务模式」。两种模式复用项目已有素材，不新增动画资源。

- 挂机模式：沿用原有随机动作、漫游和事件联动。
- 任务模式：暂停随机挂机动作、漫游、自动碎碎念和自动余额展示；没有任务时播放原有待机动画。气泡与动作共同使用一条延后约 300 毫秒的展示时间线，同时利用该窗口判断连续思考时长：不足 300 毫秒就结束的思考会整段跳过，之前的动作和气泡继续显示；达到 300 毫秒后，若没有最近操作摘要，则显示思考动作与灯泡；摘要仍在显示时延续对应操作动作。思考期间的文字更新和后台会话事件不会重新计算这段思考的起点。同类动作期间文字更新不会重新播放动画，素材自然播放结束后的原有轮换继续生效。连续三秒内的操作同时合并为简短摘要，例如「读取 12 个文件 · 搜索 7 次」。
- 点击、拖拽、手动动作和对话继续使用原有交互；互动结束后恢复当前任务动画。外部占用锁仍然优先。

新任务出现时，宠物旁提供「进入任务模式」和「继续挂机」两个按钮；进入后固定跟踪该会话。多个任务的提示逐个出现，已经结束的后台任务会从提示队列移除，过期点击无法选中其他任务。

所跟踪任务完成、失败或取消后自动回到挂机模式，等待权限或用户操作时继续任务模式。后台会话结束不会改变当前模式，目标任务的自动续跑中间回合也不会被误判为整体完成。

进入任务模式后，可以从「跟踪任务」选择一个会话，也可以选择自动模式；自动模式选定会话后会持续跟踪，其他对话的高优先级事件不会替换气泡来源。菜单列出本次宿主启动后观察到的最多 32 个会话，以首次公开用户消息的简短文本区分；既有历史会话需要发生新事件后才会出现。重启宿主后恢复挂机模式。

当前模式和所选会话由宿主共享，桌面端与网页端同步，多只宠物也使用相同选择。

任务动作按操作类别选择：修改或编写文件复用已有「写代码」，查看图片复用已有「东张西望」，其他工具沿用配置中的忙碌动作。同类操作更新文件名时继续当前动画；操作类别改变时切换对应动作。最近操作摘要保留期间，对应动作也继续播放，摘要过期后才恢复纯思考动作，避免出现「刚才修改」配思考姿势的情况。点击、拖拽等互动结束后恢复当前任务对应动作。复用观望动作时不会触发原有转向动画结束后的朝向翻转；自定义宠物未声明这些素材时，继续使用它自己的工作状态动画。

宿主最多保留最近 256 条展示快照，前端按记录时间加 300 毫秒播放，避免一次长轮询只读到快速调用的最后结果。切换跟踪来源会取消旧来源尚未展示的记录；新打开的窗口从最新状态开始。窗口长时间挂起、连接中断或超过记录容量时，从可用记录继续显示；显示器刷新率和窗口调度也会影响短暂状态的实际可见时间，因此统一延后本身不会消除闪烁。

## 数据范围与验证

气泡来自 DSH 会话事件中的工具调用、任务清单、等待与回合结束状态。气泡中的最近操作摘要继续保留原有三秒窗口，窗口结束后再显示思考灯泡和纯思考动作，避免快速返回的工具操作一闪而过。查看图片单独显示「查看图片」及简短文件名；混合操作摘要优先列出最新操作类别。该判断依据持续时间，无法识别思考内容是否属于规划。工具摘要采用简短动作、文件名或命令动作，不复制完整工具参数及输出，也没有提取实时思维内容。

验证包含状态聚合单元测试、实际宿主路由与长轮询测试，以及 Windows 原生 Electron 窗口检查。桌面自动化使用模拟会话事件，覆盖快速工具调用、并行会话、逐个提示、过期点击、自动挂机、动作切换及资源解码；另已在 Windows 的 DSH Desktop 2.0.18 中本机试用。Linux 与 macOS 的实际桌面行为仍需验证。

## 构建与接口

从源码安装前运行 `npm run build`，完整生成 `lib` 和 `runtime/electron-helper/shared-core.js`，避免混用不同版本的运行文件。

`GET /dsh-pet-7340/work-tracking` 读取当前模式与会话；`POST` 接受模式选择、会话选择或任务提示响应。未启用功能时均返回 404。前端展示数据仍由统一的 `/state` 提供，新增元数据位于 `sections.workStatus.data.progress`。参数与响应结构见仓库根目录的 `openapi.yaml`。
